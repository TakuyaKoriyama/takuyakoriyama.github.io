研究者サイト刷新案 — 更新とレビューの手引き

対象: c113d01901d7303dc1f4eae014c471017220f294 (master, 2026-10-30調査)

この変更はトップページ、/publications/、/cv/ の表示を刷新し、/blog/ を追加するものです。
公開元の設定変更・既存ファイルの削除は含みません。既存のその他のページは旧テーマで表示されます。

更新箇所
- 論文: _data/researcher.json
  papers[] に title / url / authors / venue / year / category / links を記載。
  journal は太字にする掲載誌名（任意）。venue の先頭にある名称と一致させる。
  category は Preprint または Publication。URL 未確定の論文は空文字にする。
  著者順・alphabetical order の注記・掲載情報は元の記載を保持する。
  Publications は年降順、同年内はデータの順に表示。件数は自動集計。
- 自己紹介・研究内容のレイアウト: _layouts/researcher.html
- 学歴・職歴: _includes/researcher/cv.html
- メール・Scholar・GitHub・LinkedIn・arXiv: _config.yml の author
- 研究ブログ: _research_blog/ の Markdown。手順は _docs/BLOGGING.txt。
  専用コレクションを使い、旧テンプレートの _posts は一覧・RSS に含めない。
  published: true を明示した記事だけを公開。現時点では本人の記事なし。
- デザイン: assets/css/researcher.css
- CV: cv.tex と out/cv.pdf。PDF URL は /out/cv.pdf のまま維持。
- 写真: images/profile_new.jpg。新レイアウトでは同じ写真を使用。

確認方法
既存の開発環境では bundle install の後、bundle exec jekyll serve。
公開と同じ安全モードを確かめる場合は bundle exec jekyll build --safe。
/、/publications/、/cv/、/blog/、/blog/feed.xml、/about/、/about.html、/resume、および CV/スライドのリンクを確認する。
スマートフォン幅、キーボード、印刷表示も確認する。
Google Analytics は既存設定を維持し、新レイアウトでは production 環境でのみ読込。
_config.yml の whitelist に既に使用中の jekyll-redirect-from を追加。
従来の転送設定が --safe ビルドでも実際に生成されるようにした。

公開する場合
Settings > Pages は master / (root) を公開元に指定している。
このブランチを master にマージすると GitHub Pages が自動公開するため、マージ前に本人確認を得る。
今回の差分は変更のレビュー用。公開・削除の承認には代わらない。
取り消す場合は、この刷新変更のみを revert すれば旧表示へ戻る。PDF URL は変わらない。
