Research blog の書き方

トップページの Blog は最近の3件、/blog/ は全記事を表示します。
既存テンプレートの _posts は使いません。新しい記事は _research_blog/ に置きます。
RSS は /blog/feed.xml です。現在、公開記事はなく、一覧と RSS は空です。

1. _research_blog フォルダーを作り、topic-name.md のような名前で記事を保存します。
2. 次の先頭設定と本文を記入します。

---
title: "記事のタイトル"
date: 2026-10-30 12:00:00 -0500
description: "一覧に表示する短い説明"
published: false
math: true
lang: ja
---

ここから Markdown の本文です。本文内の見出しは ## から始めます。

## 節の見出し

インラインの数式は $x^2$、独立した数式は次のように書けます。

$$
\mathbb{E}[X] = \int x\, dP(x)
$$

コードブロック、図、表、リンク、脚注も通常の Markdown で書けます。

設定の意味
- title: 記事タイトル。
- date: 実際の公開日時。URL は日付から独立して /blog/topic-name/ になります。
- description: トップ・記事一覧・RSS の要約。
- published: false のままならビルド時も非公開。省略時も false です。
- math: true の記事だけ、既存サイトと同じ MathJax 3 を読み込みます。
  数式がなければ false にします。コードや数式が長い場合は記事内だけ横スクロールします。
- lang: ja または en。省略時は en。
- updated: 追記した日を指定すると記事の公開日と別に更新日を表示できます。

記事を公開する場合
プレビューで内容を確認してから published: true に変更します。
日付だけで公開を予約する仕組みではありません。既存サイトの future: true は変更していないため、
published: true にした記事は将来の日付でも公開対象です。
今回の刷新案全体と同様、master へのマージはサイトの自動公開を伴います。
このチャットで作成した下書きやコードの存在は、公開の承認を意味しません。

画像
images/blog/ に画像を置く場合、本文では次の形式が使えます。
![画像の説明]({{ '/images/blog/figure.png' | relative_url }})
既存の CV・スライドの URL を変える必要はありません。
